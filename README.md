## 🚀 Featured Project: NEXUS
> **가맹점-본사 통합 SCM 및 자동 정산 솔루션 (Monolithic Backend)**  
> *본사와 가맹점 간의 거래 데이터를 무결하게 수집하고, 정기 구독 형태의 자동 결제 스케줄러와 철저한 부하 테스트를 직접 주도하며 신뢰성 높은 백엔드를 완성했습니다.*

### **🔑 핵심 기여 및 해결 과제**
* **💳 토스페이먼츠 연동 정기 결제 스케줄러 설계**
  * 매월 10일 정기 자동 결제를 위해 `@Scheduled` 기반 스케줄러 및 토스페이먼츠 빌링 API 결제 파이프라인 구축.
  * 복잡한 대량의 미납 거래 데이터 수집 및 예외 발생 시 다른 가맹점 결제에 영향이 가지 않도록 **결제 독립 트랜잭션 격리 구조** 설계.
* **🛡️ Spring Security & JWT 이중 인증 필터 구축**
  * 브라우저 환경(Set-Cookie - `CTOKEN` 쿠키)과 API 명세 환경(Authorization - `Bearer` 헤더)을 모두 수용하는 이중 JWT 인증 체계 설계.
  * 본사/가맹점 권한에 따른 엄격한 접근 권한 관리(RBAC) 적용.
* **⚡ nGrinder 부하 테스트 및 API 최적화**
  * nGrinder 분산 테스트 환경에서 멀티 스레드 간의 세션/쿠키 유실 문제를 극복하기 위해, **동적 JWT 추출 및 직접 헤더 주입 방식의 Groovy 스크립트** 작성 및 부하 테스트 주도.
  * 시스템 부하 한계를 사전 예측하고 동시 요청 병목 지점 개선.
